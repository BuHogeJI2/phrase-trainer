# RU-DE Phrase Trainer

Мобильное PWA-приложение для русскоязычных экспатов: бытовые немецкие фразы A1/A2 с практикой `RU -> DE` и `DE -> RU`.

## Что реализовано

- Русскоязычный интерфейс (главная, ситуации, практика, избранное, настройки)
- 10 ситуаций x 20 фраз (всего 200)
- Фильтрация по уровням `A1`, `A2`, `Все`
- Режимы практики: флеш-карточки и тест с вариантами
- Избранное + отдельная практика по избранному
- Daily-сессия: "Сегодняшние 10 фраз"
- Карточка "Продолжить с последней сессии"
- Локальный прогресс: изученные фразы, статистика тестов, серия
- Бейджи прогресса
- PWA shell (offline-ready через service worker)

## Стек

- React 19 + TypeScript
- Vite 7
- Tailwind CSS 4
- React Router
- Vitest + Testing Library
- vite-plugin-pwa

## Запуск

```bash
npm install
npm run dev
```

## Проверки

```bash
pnpm lint
npm run test:run
npm run build
```

## Аудио

Фразы ожидают mp3-файлы в `public/audio` с форматом имен:

```text
<situationId>-<NN>.mp3
# пример: transport-01.mp3
```

Если файла нет, приложение использует fallback через браузерный TTS.
