# Data Model

## Content Model

The content model is source-driven and stored directly in TypeScript files.

### Situations

Each situation in `src/data/situations.ts` includes:

- `id`
- `slug`
- `titleRu`
- `icon`
- `order`

Current catalog shape:

- 10 situations
- stable route slug per situation
- ordered display on the home page

### Phrases

`src/data/phrases.ts` keeps a `catalog` of phrase seeds and derives the exported `phrases` array from it.

Each seed defines:

- `de`
- `ru`
- `level`

Each exported phrase adds:

- `id`: `<situationId>-<NN>`
- `situationId`
- `translitRu`: generated by `transliterateGermanToRu`
- `audioDeSrc`: `/audio/<situationId>-<NN>.mp3`
- `tags`: `[level, situationId]`

An assertion fails during module evaluation if any situation does not contain exactly 20 phrases.

## Learning State

User state is persisted in browser storage under:

```text
ru-de-phrase-trainer-state-v1
```

Persisted shape:

```ts
interface AppState {
  prefs: {
    direction: 'ru_to_de' | 'de_to_ru'
    defaultLevel: 'A1' | 'A2' | 'all'
    transliterationEnabled: boolean
    audioAutoplay: boolean
    onboardingCompleted: boolean
  }
  progress: {
    completedPhraseIds: string[]
    savedPhraseIds: string[]
    quizStats: {
      totalAnswered: number
      correct: number
      streak: number
    }
    lastVisitedSituationId: string | null
    lastVisitedAt: string | null
  }
}
```

`loadStateFromStorage()` validates fields defensively and falls back to defaults when values are invalid.

## Derived Data

The app also relies on several derived structures:

- `situationBySlug` and `situationById` maps in `src/data/situations.ts`
- `phrasesBySituation` and `phraseById` in `src/data/phrases.ts`
- quiz questions built from a visible phrase pool
- badge status computed from progress counts and streaks

## Audio Assets

Optional German recordings live in `public/audio/`.

Naming rule:

```text
<situationId>-<NN>.mp3
```

Example:

```text
transport-01.mp3
```

If no matching file exists, the app uses the browser TTS fallback instead of treating the phrase as broken.
